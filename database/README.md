# Database

Drizzle migrations are generated by the `@vowly/api` package and written to
`./migrations`. The `wrangler.toml` in `workers/api` points to this directory.

## Scripts

Generate a migration from the current schema:

```bash
pnpm db:generate
```

Apply migrations to the local D1 database:

```bash
pnpm db:migrate:local
```

Seed an admin user locally:

```bash
pnpm seed:admin:local --username admin --password <strong-secret>
```

Use `--remote` instead of `--local` for production/staging after creating the D1
database with `wrangler d1 create`.
